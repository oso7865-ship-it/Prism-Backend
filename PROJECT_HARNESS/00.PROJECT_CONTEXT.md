# PRism Project Context

이 저장소에 부착된 HARNESS의 출처는 manifest.json의 harnessSource다. 원본의 유지보수 이력은 제품 구현 이력이 아니다.

등록 문서:
- README.md: 실행 방법·검증·현재 범위. 담당: PRism 유지관리자.
- docs/ARCHITECTURE.md: 제품 아키텍처 원본·기준 커밋·변경 절차. 담당: PRism 유지관리자.

manifest.json의 현재 작업 route에 해당하는 문서만 읽는다. 제품 계약 충돌은 architecture.json의 원본 커밋과 소유 문서를 확인하고 ADR로 해결한다. 사용자 최신 지시와 상위 실행 규칙을 적용한다. sibling 폴더의 존재나 상위 폴더 하네스 자동 로딩에 의존하지 않는다.
