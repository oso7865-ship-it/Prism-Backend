# Document Gate

> 대상: 일반 Markdown 문서, SRS, 설명서, 하네스 규칙 문서

## 1. 검사 항목

| 항목 | PASS | WARN | FAIL |
|---|---|---|---|
| 제목 | 대제목이 명확함 | 제목은 있으나 목적이 흐림 | 제목 없음 |
| 목적 | 문서 목적이 있음 | 목적이 짧거나 애매함 | 목적 없음 |
| 범위 | 적용 범위가 있음 | 범위가 일부 모호함 | 범위 없음 |
| 구조 | 섹션이 논리적임 | 섹션 순서가 일부 어색함 | 구조가 없음 |
| 용어 | 고정 용어를 따름 | 일부 혼용 | 용어 충돌 심함 |
| 검수 기준 | PASS/WARN/FAIL 또는 체크리스트 있음 | 검수 기준이 약함 | 검수 기준 없음 |

## 2. 문서 연결 구조

```mermaid
flowchart LR
    A[문서 초안] --> B[목적/범위 확인]
    B --> C[필수 섹션 확인]
    C --> D[용어 통일 확인]
    D --> E[Gate/Checklist 연결]
    E --> F[PASS/WARN/FAIL]
```

## 3. FAIL 기준

- 문서 목적이 없음
- 적용 범위가 없음
- 기존 하네스 용어와 충돌함
- 검수 기준 없이 산출물만 존재함

요약: 문서 초안의 목적, 범위, 구조, 용어, 검수 기준을 확인한 뒤 PASS/WARN/FAIL을 판정한다.

항목별 결과를 Checklist 판정으로 합치는 집계 규칙은 `08.QUALITY_GATE.md §7-1`이 소유한다(하나라도 필수 항목이 FAIL이면 전체 FAIL). 이 문서는 규칙을 복제하지 않는다.

## 4. SRS Context Pack 참조 규칙

SRS 문서 세트를 검수할 때 원본, 추출본, 요약본, 색인, 후보 메모가 함께 있으면 `checklists/srs-checklist.md §0-1`의 우선순위를 따른다.

요약본이나 색인은 탐색 보조 문서이며, 원본 SRS를 대체하지 않는다.
