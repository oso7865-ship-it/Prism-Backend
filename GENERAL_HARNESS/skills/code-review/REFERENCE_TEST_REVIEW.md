# Reference: 기존 테스트 품질 검수

> `skills/code-review/SKILL.md`의 보조 문서다. 기존 테스트를 검토할 때만 읽는다. brooks-lint test-guide·test-decay-risks의 원칙을 재작성했으며 원 고지는 `skills/code-review/LICENSE`에 보존한다.

## 확인할 질문

| 위험 | 실제 확인할 증거 | 오탐 방지 |
|---|---|---|
| 취약한 테스트 | 동작이 같은 내부 리팩터링에도 깨지는 호출 횟수·내부 구조 assertion | 호출 자체가 계약인 경우는 유지 |
| 읽기 어려움 | 준비·실행·결과가 섞여 실패한 업무 조건을 알기 어려움 | 테스트 길이만으로 판정하지 않음 |
| 중복·느림 | 동일 업무 조건을 여러 수준에서 같은 방식으로 반복 | 통합 경계와 사용자 흐름이 다른 위험을 검증하면 정당함 |
| mock 과용 | 반환값을 직접 주입하고 같은 값만 확인; 실제 외부 계약 차이를 검출 못함 | 시간·결제 등 외부 부작용의 격리는 필요 |
| 커버리지 착시 | assertion 없는 실행, 실패 경로 누락, 기대값을 구현에서 그대로 계산 | 커버리지 수치 자체는 결함이 아님 |
| 구조·격리 문제 | 공유 상태·순서 의존, 변경할 레거시 동작을 보호할 테스트 부재 | 테스트를 위해 운영 API를 불필요하게 공개하지 않음 |

## 결과와 연결

지적은 테스트 위치, 놓치는 결함의 예, 최소 수정안과 재검증 방법을 포함한다. 변경 동작을 보호할 사례가 없다면 `skills/test-design/SKILL.md`로 넘긴다. 실행하지 않은 결함 주입·회귀·순서 변경 시험을 실행했다고 쓰지 않는다. PASS/WARN/FAIL은 상위 리뷰 스킬의 산출물 기준을 따르며 테스트 실행 결과는 별도다.
