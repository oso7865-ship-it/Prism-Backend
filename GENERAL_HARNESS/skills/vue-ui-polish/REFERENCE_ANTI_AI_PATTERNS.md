# Anti-AI Patterns

> `skills/vue-ui-polish/SKILL.md`의 보조 참조 문서다. 단독 스킬이 아니며, 상위 스킬의 Harness Control Rule(Vue 3 스택 한정 포함)을 그대로 따른다.

패턴 이름만 보고 실패시키지 마라. 화면 목적, 콘텐츠, 기존 시스템을 확인하고 “기본값이라서 선택됐는가”를 판단하라.

## 필수 실패

### 조작된 신뢰

제공되지 않은 사용자 수, 전환율, 후기, 고객사 로고, 수상 경력, 사례를 만들어 신뢰를 연출한다.

**수정:** 실제 자료를 요청하거나 명확한 자리 표시자로 두거나 해당 블록을 제거한다.

### 상태 없는 상호작용

요청이 진행되는데 로딩이 없거나, 실패했는데 이유·재시도 경로가 없거나, 비활성 상태의 이유가 전달되지 않는다.

**수정:** 기능 흐름에 실제로 필요한 상태와 다음 행동을 구현한다.

### 토큰 이탈

기존 토큰과 공통 컴포넌트가 있는데 페이지 내부에서 색상·간격·그림자·모서리를 새로 만든다.

**수정:** 기존 의미 토큰을 사용하거나 공통 시스템에 필요한 역할을 추가한다.

### 가짜 장치 프레임

실제 콘텐츠를 돋보이게 하려고 브라우저 신호등, URL 바, 휴대폰 테두리, IDE 제목 표시줄을 장식으로 다시 그린다.

**수정:** 실제 스크린샷을 단순한 figure로 보여주거나 콘텐츠 자체를 보여준다.

### 접근성 은폐

`outline: none`으로 포커스를 없애거나, hover에서만 정보를 보여주거나, 낮은 대비와 모션으로 의미를 전달한다.

**수정:** 모든 입력 방식에서 동일한 정보와 행동을 제공한다.

## 강한 경고

### 템플릿형 랜딩 리듬

중앙 영웅 영역 → 같은 크기의 기능 카드 3개 → 로고 벽 → CTA → 푸터가 콘텐츠와 무관하게 반복된다.

**판단:** 실제 콘텐츠가 정확히 이 구조를 요구하는지 확인하고, 아니라면 과업·증거·이야기의 순서로 다시 구성한다.

### 카드 과잉과 카드 속 카드

정보 그룹마다 둥근 상자와 그림자를 사용해 위계 대신 컨테이너 수가 늘어난다.

**수정:** 간격, 제목, 헤어라인, 배경 단계 중 하나로 그룹을 표현한다.

### 모든 요소의 동일한 무게

같은 크기 카드, 같은 아이콘, 같은 제목 길이, 같은 버튼으로 우선순위가 사라진다.

**수정:** 실제 중요도와 사용 빈도에 따라 밀도·위치·강조를 달리한다.

### 장식용 그라데이션과 발광

보라·파랑 그라데이션, gradient text, glow가 브랜드나 정보 의미 없이 사용된다.

**수정:** 하나의 강조색과 명확한 역할을 사용한다. 브랜드가 그라데이션을 보유하거나 데이터 의미가 있으면 허용한다.

### 필 모양 남용

제목, 라벨, 내비게이션, 버튼, 상태가 모두 pill이 되어 구분이 사라진다.

**수정:** 실제 선택·필터·상태처럼 pill이 의미 있는 곳에만 사용한다.

### 과도한 중앙 정렬

eyebrow, 제목, 설명, CTA, 이미지가 모두 같은 중앙축에 쌓여 정보의 방향성이 없다.

**수정:** 중심 요소는 유지하되 보조 정보나 행동을 콘텐츠 흐름에 맞춰 배치한다.

### 범용 문구

“경험을 혁신하세요”, “가능성을 열어보세요”, “Seamless”처럼 제품을 바꿔도 그대로 쓸 수 있는 문구를 사용한다.

**수정:** 사용자가 하는 행동과 얻는 결과를 실제 명사·동사로 쓴다.

### 모션 복사

모든 요소에 fade-up, stagger, hover lift, scale을 반복한다.

**수정:** 상태 전달과 공간 연결에 필요한 요소만 움직인다.

### 근거 없는 프리미엄 공식

현대적·프리미엄·라이프스타일이라는 이유만으로 명조 display, 크림색 종이 배경, 점토·황동 계열 강조색, 진한 갈색 본문을 한 세트로 반복한다.

**수정:** 브랜드 자료와 상품 성격을 먼저 확인한다. 근거가 없으면 같은 분위기를 차가운 중성색, 산세리프 display, 단색 대비, 선명한 단일 강조색 등 다른 조합으로 표현한다.

### 장식용 혼합 서체

제목 한 단어만 임의의 명조체나 이탤릭 계열로 바꿔 시각적 흥미를 만든다.

**수정:** 한 글꼴 가족의 굵기·폭·이탤릭을 먼저 활용한다. 다른 글꼴은 브랜드 또는 콘텐츠 역할이 분명할 때만 추가한다.

### 섹션 구조 복사

여러 섹션이 제목 위치, 카드 수, 이미지 비율, CTA 위치까지 같은 골격을 반복한다.

**수정:** 과업에 따라 목록, 비교, 편집형 서사, 실제 데모, 비대칭 그리드처럼 구조 가족을 바꾼다. 같은 목적의 반복 화면은 학습 가능성을 위해 그대로 유지한다.

### 새로움을 위한 무작위성

사용자 의도와 무관하게 레이아웃·서체·모션을 무작위로 선택하거나, 이전 결과와 달라 보이는 것을 품질로 간주한다.

**수정:** `skills/vue-ui-polish/REFERENCE_TASTE_STRATEGY.md`의 디자인 해석에서 선택 근거를 만든다. 차이는 과업·콘텐츠·브랜드에서 나오게 한다.

## 맥락상 허용되는 선택

다음은 단독으로 AI 티의 증거가 아니다.

- Inter나 system font: 기존 제품 시스템이거나 읽기 중심 앱이면 적절할 수 있다.
- 3열 카드: 정확히 세 대상을 비교하고 열 구조가 이해를 돕는다면 적절하다.
- 중앙 영웅 영역: 하나의 캠페인 메시지나 이미지가 중심이면 적절하다.
- 순백색: 기존 브랜드와 대비 체계가 이를 요구하면 적절하다.
- 그라데이션: 브랜드 자산, 데이터 규모, 실제 조명 표현처럼 역할이 있으면 적절하다.
- 명조체와 따뜻한 종이색: 출판·전통·헤리티지·브랜드 자산처럼 구체적인 근거가 있으면 적절하다.

허용할 때는 “왜 이 패턴이 이 화면의 목적에 맞는가”를 한 문장으로 설명한다.
