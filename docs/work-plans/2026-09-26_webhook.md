# Webhook 자동 PR 동기화 구현 계획

## 작업 계약
- 목표: 서명된 GitHub 이벤트를 영속 수신하고 PR 자동 동기화·설치 권한 철회를 처리한다.
- 범위: 다음 묶음의 첫 단계(Webhook). 정적 분석 실행기·규칙·DeepSeek·UI 재설계·공개 수신 주소·하네스 동기화는 후속 단계다.
- 브랜치: backend dev, architecture main. 기존 미커밋 변경 보존, Git 게시 없음.
- 근거: CORE, WEBHOOK, DB-EXECUTION, PR-SYNC, JOBS. planning/terminal-ops/verification-loop 적용.
- 위험: DB/인증. 기존 사용자 구현 요청 근거. 원문 HMAC, 1 MiB body 상한, 최소 식별자만 저장, Workspace→repository→delivery→Job 잠금, generation fence, 재연결 자동 복원 금지. 사전 Security/DB 설계 PASS, 사후 검증 별도.
- 영향: webhook 신규 도메인·0004 migration, repository/workspace/pull_request 공개 시스템 계약, runner registry/config, 테스트·운영 문서. UI 변경 없음.
